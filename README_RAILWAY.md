# TokoMadura CI3 Railway Ready

1. Push folder ini ke GitHub.
2. Deploy di Railway menggunakan Dockerfile.
3. Tambahkan MySQL service.
4. Isi variables MYSQLHOST, MYSQLPORT, MYSQLUSER, MYSQLPASSWORD, MYSQLDATABASE.
5. Import SQL dari folder database.
6. Generate domain Railway.
7. Tes /health.php dan /login.

Jangan menambahkan /TokoMadura_CI3 pada URL Railway.
